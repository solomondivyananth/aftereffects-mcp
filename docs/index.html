Read. Edit. Look.

The model works the way an animator does: it reads what's there, makes one change, and renders the frame to check its own work before telling you it's done.

READ

The real property tree: keyframes, eases, expressions, text animators, trim paths, masks. It sees animation that lives outside Transform too.

ae_comp_tree {"comp": "Hero 16x9"} → 14 layers · "Title" animates Text › Animators › Opacity (6 keys)

EDIT

Keyframes, expressions, effects, presets, text, masks, shapes and markers, on one layer or fifty, as a single undo step.

ae_add_keyframes { "layers": "selected", "path": ["Transform","Scale"], "keys": [{"time":"0f", ...}, {"time":"12f", "ease":"easy"}]}

LOOK

It renders frames and a motion contact sheet, so it judges timing as motion, not as numbers that merely look right.

ae_review_motion {"frames": 16} → contact sheet + motion.mp4 "The overshoot lands at 0:00:00:14 — 2 frames early against the beat."

0:00:09:16 · Safe

Your project stays yours.

A sandbox guard

Writes only land in the project you mark as the sandbox, and only you can change that, from the panel. No tool can unlock it.

Locked to your machine

Loopback only, a 256-bit token, and browser requests refused. A web page you happen to visit can't drive After Effects.

A raw-script switch

The two tools that can run anything are one toggle away from off. The dedicated tools keep working.

0:00:10:00 · FAQ

Questions.

What is an After Effects MCP server?

MCP (the Model Context Protocol) is the standard way AI assistants call tools. AE MCP Bridge is an MCP server whose tools reach into a running copy of Adobe After Effects, so an assistant like Claude can read your comps, render frames to look at, and make edits directly. You don't have to copy scripts back and forth.

Which AI clients does it work with?

Any MCP client. Claude Code and Claude Desktop, Cursor, and other MCP-capable tools all connect the same way. Nothing in the bridge is specific to one client, and it needs no API key: your client brings its own model.

Will it change my project without asking?

No. A sandbox guard only allows edits to the project you mark as the sandbox, and only you can change that, from the panel. Reads and renders always work. Every edit is one step in Edit ▸ Undo.

Which versions of After Effects are supported?

After Effects 2022 (22.0) and later, on macOS and Windows, using a CEP panel and ExtendScript, which is the route to After Effects' full scripting object model.

Can it render video?

Yes. It runs background renders with aerender, so After Effects stays usable. It can also drive the Render Queue panel and hand jobs to Adobe Media Encoder.
